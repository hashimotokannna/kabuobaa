# Kabuobaa Web

おばあさんの株手法（毎日の四本値記録・安くなったら買い・決めたルールで売る）をWeb化したシステム。
下準備はGitHub Actionsが自動実行し、判断と注文は人間が行います。

公開ページ: `https://<ユーザー名>.github.io/<リポジトリ名>/`（合言葉で施錠）

## 画面構成

| ページ | 内容 |
|---|---|
| 帳簿 (index.html) | 根拠スコア順の厳選10銘柄。持ち金連動・★お気に入り・事実コメント・選定基準の明示 |
| 持ち株 (holdings.html) | 保有銘柄の登録と売り判断（利確%・損切り%を設定、到達で色付き表示） |
| 全銘柄 (universe.html) | 約4,000銘柄の判定台帳（候補/圏外はスコア、除外/対象外は理由付き） |
| 検証 (backtest.html) | 過去1年の仮想実行。持ち金別(30万〜無制限)・損切り%別(なし〜−12%)の成績比較 |
| 使い方 (guide.html) | 使い方ガイド（仕様変更に自動追随） |

持ち金・売りルール・お気に入り・持ち株・合言葉の記憶は、すべて閲覧端末のlocalStorageにのみ保存。
リポジトリと公開ページに個人情報は含まれません。

## 仕組み

```
GitHub Actions（平日 9:40〜14:40毎時 + 15:45 + 20:30 JST）
  └─ screener.py
       1. JPX公式の上場銘柄一覧（+札証・福証の単独上場銘柄）を取得
       2. 各銘柄の日足1年分をYahoo Financeから並列取得（10〜20分）
       3. 対象外（流動性・低位株・上場浅）と除外（終わった株・急落・荒い値動き・下げ止まり未確認）
       4. 5観点の根拠スコアで採点し候補40銘柄を選定
       5. 仮想実行（利確+5%、損切りなし/−5/−8/−12%比較、持ち金別比較）
       6. 全ページ生成 → 合言葉で暗号化（PAGE_PASSWORD）→ コミット・公開
GitHub Pages が docs/ を公開 → iPhoneのホーム画面から閲覧
```

## セットアップ（初回のみ）

1. Publicリポジトリを作成し、このフォルダの中身をアップロード
   - `nightly.yml` はリポジトリの `.github/workflows/nightly.yml` に配置
2. Settings → Secrets and variables → Actions に `PAGE_PASSWORD`（ページの合言葉）を登録
3. Settings → Pages → Deploy from a branch → `main` / `/docs` → Save
4. Actions → nightly-screener → Run workflow（limit欄に50でテスト実行、空欄で本実行）
5. 公開URLをiPhoneのSafariで開き「ホーム画面に追加」

## 調整

`screener.py` 冒頭の `CONFIG` の数字を変えるだけ。主な項目:
利確% (TP_PCT)、厳選数 (TOP_N)、◎○の閾値、終わった株・急落・値動きの荒さの除外基準、流動性下限。
選定基準の画面表示は設定値から自動生成されるので、変更すると表示も追随します。

動作確認は `python screener.py --demo`（ネット不要・ダミーデータでページ生成）。

- 株価はYahoo Financeの非公式な取得口。仕様変更時はJ-Quants API（JPX公式）への差し替えが正攻法
