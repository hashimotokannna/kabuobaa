はじめに — この株ノートの使い方
役割分担・毎晩の流れ・タブの意味 ・ 9/12（土）時点の仕様
🟢 これは何？
おじいさま・おばあさまの株手法（毎日の四本値記録・普段より安くなったら買い・決めたルールで売る）をWeb化。 下準備はシステムが自動、買う・売るの判断と注文はあなた。注文機能はありません。
🔵 毎晩の流れ（1〜2分）
  1. 「今夜の厳選」を開く ホーム画面のアイコン → 合言葉（記憶した端末は自動）
  2. 厳選10銘柄を見る タップで根拠・チャート・ノート・会社の発表が開く
  3. 買うなら 銘柄内の「買った→持ち株に登録」を押してから証券会社アプリで注文
  4. 売りはルールで機械的に 推奨は利確+10%・損切り−5%のIFDOCO注文。このルールの実力は「IFDOCOシミュレーション」（このページ最下部）で毎晩検証されています
📒 タブの役割
今夜の厳選安全×質×タイミングの三層で選んだ厳選10銘柄＋「まもなく買い場」の待ち銘柄。持ち金・★・根拠
全銘柄台帳約4,000銘柄の台帳。安全（減点）・質・タイミングの3スコア、無傷／まもなく絞り込み、並べ替え、タップで全詳細（指標メーター付き）
指標の読み方PER・RSIなど全指標の図解。数字の読み方はここ
銘柄マップ全銘柄を財務×テクニカル×値動きでベクトル化した3D空間。似ている銘柄が近くに並び、タップで「発想が繋がる銘柄」へ光の糸が伸びる
時価総額マップ株価×発行株式数の平面に全銘柄を配置。右上ほど時価総額が大きく、100億〜10兆円の等高線で市場の全体像がひと目でわかる
🟡 選定の仕組み（要約）
全銘柄 → 対象外（流動性不足・低位株・上場浅）→ 除外（終わった株・急落直後・荒い値動き・下げ止まり未確認）→ 残りを6観点で採点（安さ／下げの質／トレンド／過去1年の利確実績／長期テクニカル／財務健全性）→ 上位60が候補 → 持ち金で買える10銘柄を表示。 詳細は「今夜の厳選」の「選定基準」カードと各銘柄の根拠。
🔴 大事な前提
・持ち金・売りルール・★・持ち株・売却履歴・合言葉の記憶はすべてこの端末の中だけに保存（iPhoneとMacで別）
・データはJPX公式・Yahoo Finance・TDnet。表示は毎時の「写真」で、リアルタイムはYahooリンクで
・このサイトは判断材料の表示のみ。投資判断は自己責任で
🧩 シミュレーションとTOB素地（上のタブから開けます）
シミュレーション（パターンA〜G）おばあ理論に加え、急落リバウンド・好決算ドリフト・割安×高収益・新高値モメンタム・出来高急増の6戦略を、同じ売買ルール（+10%利確/−5%損切）で過去1年分並走検証。毎晩の実測1位も自動記帳 TOB素地ランキング買収・非公開化されやすい「体質」を診断士の定石（PBR・時価総額・ため込み度など9観点）で全銘柄採点した順位表。確率の予測ではなく、最後の確認は人間の役割
⚙️ 操作のコツ・初期設定
スワイプで左右のタブへ移動 ／ 銘柄コード（例 2489 ⧉）をタップでコピー ／ SBIアプリ連携は1回だけ設定：ショートカットApp →「＋」→「Appを開く」→ SBI証券 株 → 名前を「SBIへ」に
更新タイミング 平日 9:40〜14:40毎時・15:45・20:30（夜が入れ替え基準）。実行に30〜60分かかるため表示は最大1時間前の値です
「🔄 更新」ボタン（「今夜の厳選」と「全銘柄台帳」の右上）はページの再読み込み（F5と同じ）。スマホでも最新の記帳に切り替えられます
仕様を変えるとこのページも自動で追随します。数字の読み方は「指標の読み方」ページへ。
