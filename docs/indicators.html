指標の読み方 — 数字を判断に変える図解
数字を「読める」ようになるための図解 ・ タップで開閉 ・ 8/23（日）時点の採点基準

色の意味（全指標共通）

安心・標準（迷わず見られる）魅力あり・要確認（割安の罠などを確認）注意・様子見警戒中立
価値系（PER・PBR・ROE）は「標準」が最も安心な位置で、「割安」は魅力だが理由の確認が要る位置。行きすぎ系（RSI・ボリンジャー等）は売られすぎ側が押し目買いに有利。▲は具体例の位置。各指標をタップすると、子供向けのたとえ・メーター・数値別の見方・落とし穴・採点での扱いが開きます。
主要指標（採点の中心・13）
PERの材料EPS（1株あたり利益）›
会社の1年の利益を発行株数で割った「1株が稼いだ金額」。株価 ÷ EPS ＝ PER。
🧒 クラス全員でお店をやって100万円もうかったら、40人で割ってひとり2.5万円。これが「1株あたりの取り分」＝EPS。
具体例：この数字ならこう見る
EPS 150円株価1,500円ならPER10倍。EPSが毎年伸びている会社は、株価が同じなら年々割安になっていく。
EPS 横ばい金額の大小そのものに良し悪しはない（株数で変わるため）。大事なのは「伸びているか」と株価との比率（PER）。
EPS マイナス赤字。PERは計算不能（マイナス）になり、このシステムでは大きく減点。
落とし穴
EPSの金額そのものを会社同士で比べても意味がない（株の分割で何倍にも変わる）。比べるのは「同じ会社の去年と今年」か、株価と割ったPER。自社株買いで株数が減るとEPSは利益が同じでも上がる。
このシステムでの扱い
単独では採点せず、株価÷EPSでPERを算出して採点。決算短信（J-Quants）の実績値を使用。予想EPSがあればPEG（成長性）にも使用。
PBRの材料BPS（1株あたり純資産）›
会社の純資産（資産−借金）を発行株数で割った「1株の持ち分の中身」。株価 ÷ BPS ＝ PBR。
🧒 会社をいま解散してぜんぶ売り払い、借金を返して残ったお金を株数で山分けしたら1株いくらか、という金額。
具体例：この数字ならこう見る
BPS 2,000円 ／ 株価 1,600円PBR0.8倍。持ち分の中身より安く買える状態。中身（資産の質・稼ぐ力）の確認が前提で加点。
BPS 500円 ／ 株価 1,500円PBR3倍。成長企業なら普通。BPS単独では判断しない。
BPSが毎年減っている赤字の垂れ流しや大きな損失で持ち分が痩せている合図。要警戒。
落とし穴
帳簿上の資産が実際に売れるとは限らない（古い工場・在庫など）。BPSが高くても「中身」の質はわからないため、ROE（その資産で稼げているか）とセットで見る。
このシステムでの扱い
単独では採点せず、株価÷BPSでPBRを算出して採点。決算短信（J-Quants）の実績値を使用。ROE＝EPS÷BPSの算出にも使用。
割安・割高PER（株価収益率）›
株価が「1年分の利益の何年分」か。低いほど利益に対して安い。
🧒 たとえば1年で100円もうかるお店を1,000円で買ったらPER10倍。10年で元が取れる、ということ。
具体例：この数字ならこう見る
8倍利益に対して株価が安い。同業比較で確認し、業績が落ちていなければ「割安」で加点。
15倍日本株の平均的な水準（標準＝安心圏）。これ単独では判断材料にならず、他の指標を見る。
70倍利益の70年分。成長期待が先行しており、期待が剥げると下げが深い。減点。
落とし穴
業績が悪化して利益が減ると見かけのPERは「上がる」。逆に一時的な特別利益で「下がる」。マイナス＝赤字。業種で水準がまったく違うので同業比較が基本。
このシステムでの扱い
20倍以下 +8点 ／ 60倍超 −10点 ／ 赤字（マイナス）−20点。減点方式では60倍超−15、赤字−30。
資産に対する値段PBR（株価純資産倍率）›
株価が「会社の純資産の何倍」か。1倍未満は理論上、会社を解散した方が高い水準。
🧒 1,000円の貯金が入った貯金箱を800円で売っている状態がPBR0.8倍。お得に見えるけど、貯金箱に穴が開いていないか（稼ぐ力）は要確認。
具体例：この数字ならこう見る
0.7倍純資産より安く売られている。ROEが低くなければ「割安の罠」ではなく本物の割安。要確認のうえ加点。
2.0倍標準的。成長企業ならこのくらいは普通。
9倍資産の9倍の値段。IT・バイオ系に多いが、資産面の下値支えがなく減点。
落とし穴
低PBRが何年も放置される「割安の罠」がある。理由は「稼ぐ力がない」か「資産の中身が悪い」。必ずROEとセットで見る。
このシステムでの扱い
0.5〜1.5倍 +6点 ／ 8倍超 −8点。
稼ぐ力ROE（自己資本利益率）›
株主のお金（純資産）で、1年にどれだけ利益を出したか。会社の「稼ぐ力」そのもの。
🧒 100万円のお小遣い元手で1年に10万円もうけたらROE10%。同じ元手で3万円しかもうからない会社より優秀。
具体例：この数字ならこう見る
15%資本効率が高い。低PBRと組み合わさっていれば「安くて稼ぐ」理想形。加点。
6%標準的。可もなく不可もなし。
1.5%元手のわりに稼げていない。低PBRの理由がこれなら「割安の罠」。減点。
落とし穴
借金を増やすとROEは見かけ上がる（レバレッジ）。極端に高いROE（40%超など）は自己資本が薄いだけの可能性もある。
このシステムでの扱い
10%以上 +8点 ／ 3%未満 −5点。減点方式では3%未満−12。
持っているだけの収入配当利回り›
株価に対する年間配当の割合。3〜4%は高配当の部類。
🧒 1,000円の株で年30円もらえたら利回り3%。銀行預金よりずっと高いが、株価は上下する。
具体例：この数字ならこう見る
3.5%配当が下値を支えやすい。押し目買いの安心材料。加点。
1.2%成長投資に回す会社に多い。配当は判断材料にならない。
7%株価急落で見かけの利回りが跳ねているか、減配前の可能性。要警戒。
落とし穴
利回り＝配当÷株価なので、株価が下がるほど利回りは上がる。高利回りが「安さの結果」なのか「業績悪化の前兆」なのか見極めが必要。
このシステムでの扱い
3%以上 +5点。
過熱感RSI（14日）›
直近14日の値動きから「買われすぎ・売られすぎ」を0〜100で示す。
🧒 ボールを地面に強く叩きつけるほど跳ね返る、の「叩きつけ度」。30以下は強く叩きつけられた状態。
具体例：この数字ならこう見る
25売られすぎ。押し目買い手法との相性が最も良い状態。加点。
50中立。判断材料にならない。
78買われすぎ。ここから買うのは高値掴みになりやすい。減点方式で減点。
落とし穴
強い下落トレンド中はRSI30以下が「続く」ことがある（張り付き）。だからこそこのシステムは「下げ止まり確認」とセットで使う。
このシステムでの扱い
30以下 +10点 ／ 40以下 +5点。減点方式では70超−6。
勢いの転換MACD›
短期と中期の平均線の差で「勢いの向き」を見る。マイナス圏からの買い転換が最も広く使われるサイン。
🧒 坂道を下っていた自転車が、ペダルを漕ぎ始めた瞬間を捉える指標。「まだ下り坂だけど勢いは上向き」がわかる。
具体例：この数字ならこう見る
買い転換（直近5日）下げの勢いが尽きて反転し始めた。押し目買いのタイミングとして最良。+8点。
上向き継続勢いは上。追随買いは可だが押し目としては遅い。+4点。
下向きまだ下げの勢いが残る。ナイフの落下中。加点なし。
落とし穴
横ばい相場ではダマシ（転換→すぐ戻る）が多い。単独では使わず、支持帯やRSIと重ねる。
このシステムでの扱い
直近5日以内の買い転換 +8点 ／ 上向き継続 +4点。
統計的な行きすぎボリンジャーバンド›
過去20日の値動きの「ばらつき（σ）」で普通の範囲を測る。−2σ以下は統計上約2%しか起きない売られすぎ。
🧒 身長の平均から極端に外れた人が珍しいのと同じ。−2σは「クラスで一番背が低い」レベルの珍しさ。珍しい状態は長続きしにくい。
具体例：この数字ならこう見る
−2.3σ統計的な売られすぎ。平均への回帰（戻り）が期待できる。+8点。
−0.5σ普通の範囲。特に材料なし。
+2.2σ買われすぎ。過熱。減点方式で減点。
落とし穴
急落局面ではバンド自体が広がって「−2σに触れたまま下げ続ける」（バンドウォーク）ことがある。下げ止まり確認とセットで。
このシステムでの扱い
−2σ以下 +8点 ／ −1.5σ以下 +4点。減点方式では+2σ超−6。
逆張りの定番25日移動平均乖離率›
25日平均線から何%離れているか。−8%を超える下方乖離は逆張りの定番圏。
🧒 ゴムひもを引っ張るほど戻る力が強くなる。ただし引っ張りすぎるとゴムが切れる（−20%超は異常事態）。
具体例：この数字ならこう見る
−12%平均線から大きく下に離れ、戻りやすい位置。+6点。
−3%通常範囲。押し目としては浅い。
−25%乖離しすぎ。決算ミス等の「何か」が起きている可能性。−5点。
落とし穴
乖離率の「戻りやすい」は平均への回帰であって、上昇トレンド復帰の保証ではない。
このシステムでの扱い
−8〜−20% +6点 ／ −20%超 −5点。減点方式でも−20%超は−10。
長期の地合いゴールデンクロス（50日/200日線）›
50日平均線が200日平均線の上にある＝長期の上昇形。押し目買い手法との相性が最も良い環境。
🧒 最近1ヶ月の平均点が、1年の平均点より高い生徒。「調子が上向きの子」の悪い日を狙うのが押し目買い。
具体例：この数字ならこう見る
GC継続中の押し目上昇トレンド中の一時的な下げ。この手法の理想形。+20点（200日線の上での下げ）+10点。
DC中の反発下落トレンド中の一時的な戻り。上値が重く、利確に届きにくい。減点方式で−10。
落とし穴
クロスの瞬間は「遅行」する（トレンドがだいぶ進んでから点灯）。タイミングではなく環境判断に使う。
このシステムでの扱い
200日線の上での下げ +20点 ／ GC中 +10点。減点方式ではDC中−10。
過去に買いが入った価格帯長期支持帯とタッチ回数›
3年の谷を集めた「何度も反発した価格帯」。定石は「〜3回目までは支持されやすく、4回目以降は割れやすい」。
🧒 同じ場所で3回転んだら、4回目はそこが崩れているかもしれない。逆に2回しか転んでいない場所はまだ丈夫。
具体例：この数字ならこう見る
過去2回反発・今3回目支持帯の直上での押し目。定石の信頼圏内。+12点。
過去4回反発・今5回目試されすぎ。次は割れる可能性が高まる。−5点・減点方式−8。
帯を明確に割った後支持帯は無効。このシステムは自動で候補から外す。
落とし穴
支持帯は「絶対の壁」ではなく「買い手が多かった記憶」。出来高を伴って割れたら素直に諦める。
このシステムでの扱い
〜3回目 +12点 ／ 4回目以降 −5点。
市場全体の風向き地合い（日経平均の200日線）›
日経平均が200日線の上か下か。下にある間は市場全体が下落基調で、個別の押し目買いの成功率も落ちる。
🧒 みんなが下り坂を歩いているときに、一人だけ上り坂を歩くのは大変。風向きを見てから歩き出す。
具体例：この数字ならこう見る
上昇基調帳簿上部に緑のバナー。普段通りに押し目を拾ってよい。
下落基調オレンジの警戒バナー。買いは普段より慎重に、株数を減らす・見送るなどの判断を。
落とし穴
地合いは「傾向」であって個別銘柄の保証にはならない。逆に、悪い地合いで下げ止まっている銘柄は強い銘柄。
このシステムでの扱い
スコアには入れず、帳簿上部のバナーで注意喚起。
準主要指標（補助的に加点・10）
過熱感（RSIの相棒）ストキャスティクス（スロー）›
直近14日の値幅の中で、いまの終値がどの位置か（0〜100）。20以下=売られすぎ、80以上=買われすぎ。
🧒 教室の身長順で、今日の自分が「一番低い側」にいるかを見る指標。RSIより反応が早い。
具体例：この数字ならこう見る
12売られすぎ。RSIとセットで低ければ押し目の信頼度が上がる。+4点。
50中立。材料にならない。
88買われすぎ。追いかけ買いは危険。
落とし穴
強いトレンド中は80以上・20以下に「張り付く」。単独では使わず、下げ止まり確認と併用。
このシステムでの扱い
20以下 +4点。
トレンドの強さと向きDMI / ADX›
ADXは「トレンドの強さ」（向きは示さない）。+DIと−DIのどちらが上かで向きが分かる。ADX25以上で「トレンドあり」。
🧒 風の強さ（ADX）と風向き（+DI/−DI）。強い追い風の中の一休み（押し目）が理想、強い向かい風なら見送り。
具体例：この数字ならこう見る
ADX30・+DI優勢上昇トレンドに勢いがある中の押し目。+4点。
ADX15方向感なし。レンジ相場。
ADX30・−DI優勢下降トレンドに勢い。ナイフの落下中。−4点。
落とし穴
ADXは遅行する。上がり始めた時点でトレンドはかなり進んでいる。環境認識用。
このシステムでの扱い
ADX25以上かつ+DI優勢 +4点／−DI優勢 −4点。
中期の地合い一目均衡表（雲）›
先行スパンで作る「雲」に対して株価が上か中か下か。雲の上=中期強気、雲の下=中期弱気、雲の中=方向感なし。
🧒 雲の上を飛んでいる飛行機は安定、雲の中は視界不良、雲の下は雨。
具体例：この数字ならこう見る
雲の上での押し目中期の支えがある下げ。+4点。
雲の中方向感なし。他の指標で判断。
雲の下中期は弱い。反発しても雲が上値抵抗になりやすい。−3点。
落とし穴
雲のねじれ（先行スパンの交差）付近は転換点になりやすく、判断が難しい。
このシステムでの扱い
雲の上 +4点／雲の下 −3点。
値幅・損切り幅の目安ATR（アベレージ・トゥルー・レンジ）›
1日にどれくらい動く銘柄か（株価比%）。損切り幅・利確幅を「その銘柄の普段の動き」に合わせるのに使う。
🧒 その人の歩幅。歩幅の小さい人は少しの距離で判断できるが、大股の人は同じ距離だとすぐ踏み越える。
具体例：この数字ならこう見る
1.5%日々の値幅が小さく、−8%損切りは十分な余裕。+3点。
3%普通。損切りは−8%で妥当。
6%1日で損切りに届く。損切り幅を広げるか、そもそも見送り。−3点。
落とし穴
ATRが小さすぎる銘柄は動かないので短期回転には向かない。「小さければ良い」ではない。
このシステムでの扱い
2%以下 +3点／5%以上 −3点。損切り%の妥当性チェックにも。
お金の流れOBV / MFI（出来高系）›
OBVは「上げた日の出来高を足し、下げた日を引く」累積線。株価が下がっているのにOBVが上向きなら「誰かが買い集めている」。MFIは出来高込みのRSI。
🧒 お店の売上（株価）は落ちているのに、常連客（出来高）が増えている——それは復活の前兆かもしれない。
具体例：この数字ならこう見る
OBV上向き＋株価下落下げの中で買い集め。反発の芽。+3点。
MFI 15出来高込みの売られすぎ。+3点。
OBV下向き＋株価横ばい静かに売り抜けられている可能性。
落とし穴
出来高の少ない銘柄では大口1件で歪む。売買代金の大きい銘柄で意味を持つ。
このシステムでの扱い
OBV20日で+5%超 +3点／MFI20以下 +3点。
値動きの荒さ（年率）ヒストリカル・ボラティリティ（HV）›
過去20日の値動きから計算した年率換算の変動率。日本株の平均は25〜35%程度。
🧒 ジェットコースターの高低差。高いほどスリルはあるが、目的地（利確）に着く前に振り落とされやすい。
具体例：この数字ならこう見る
22%落ち着いた銘柄。夜1回判断のスタイルと相性が良い。
35%普通。
75%荒すぎ。翌朝の窓開けも大きくなる。減点方式で減点対象。
落とし穴
HVが低い＝安全ではない。決算前などに急に跳ねる。
このシステムでの扱い
採点には直接使わず、ATR・夜間ギャップで代替。メーター表示のみ。
財務の厚み（倒産しにくさ）自己資本比率›
総資産のうち返さなくていいお金（自己資本）の割合。高いほど不況に強い。目安: 50%以上=厚い、20%未満=借入依存。
🧒 家の値段のうち自分のお金で払った割合。ローンだらけの家は金利が上がると危ない。
具体例：この数字ならこう見る
60%財務が厚い。下げても倒産リスクが低く、安心して押し目を拾える。+4点。
40%標準的。
12%借入依存。金利上昇や業績悪化に脆い。−5点。
落とし穴
銀行・リース・商社などは業種の性質上、低くて正常。同業比較が必須。
このシステムでの扱い
50%以上 +4点／20%未満 −5点。
本業の稼ぐ力・資産効率営業利益率 / ROA›

配当の持続性・成長との割安度配当性向 / PEG›
配当性向＝利益のうち配当に回す割合（30〜60%が健全、100%超は利益以上に配っており減配リスク）。PEG＝PER÷利益成長率（1倍以下なら成長に対して割安）。
🧒 配当性向はお小遣いのうち貯金せず使う割合。100%超は貯金を切り崩している。PEGは「伸び盛りの子の月謝が割安か」。

バリュエーション›
EPS / BPS / SPS / CFPS / DPS1株あたりの利益・純資産・売上・キャッシュフロー・配当。PER・PBR・PSR・PCFR・利回りの分母になる基礎数字。
PSR（株価売上高倍率）株価÷1株売上。赤字の成長企業をPERで測れないときの代替。1倍未満は割安寄りだが業種差が大きい。
PCFR（株価キャッシュフロー倍率）株価÷1株CF。利益より操作されにくいCFで見た割安度。
EV/EBITDA企業価値÷（営業利益+減価償却）。買収の値付けで使う指標。8倍以下は割安寄り。個人の短期売買では出番は少ない。
財務健全性・効率性›
流動比率 / 当座比率1年以内に払う負債に対し、1年以内に現金化できる資産がどれだけあるか。流動比率200%以上・当座比率100%以上が安心の目安。
D/Eレシオ有利子負債÷自己資本。1倍以下が健全の目安。
インタレスト・カバレッジ営業利益÷支払利息。利払いの余裕。10倍以上なら安心。
フリーキャッシュフロー（FCF）本業で稼いだ現金から投資を引いた残り。プラスが続く会社は自力で成長・還元できる。
粗利益率 / 経常利益率 / 純利益率売上に対する各段階の利益率。粗利は商品力、経常は財務込み、純利益は最終。
総資産回転率 / 棚卸資産回転率資産・在庫がどれだけ効率よく売上に変わっているか。低下は在庫過剰の兆し。
ROIC投下資本利益率。事業に投じたお金に対する本業の利益率。WACC（資本コスト）を上回っていれば価値を生んでいる。
テクニカル（トレンド系）›
EMA / WMA / HMA / ALMA直近を重視した移動平均の変種。SMAより反応が速い。当システムは50日/200日SMAとMACD（EMAベース）で代替。
パラボリックSARトレンドの転換点をドットで示す。追随には向くが、レンジ相場でダマシが多い。
エンベロープ / ケルトナー / ドンチャン移動平均や高値安値からの一定幅のバンド。ボリンジャーバンドの兄弟。
GMMA短期6本+長期6本の移動平均の束。束の広がりでトレンドの強さを見る。
スーパートレンドATRベースのトレンド追随線。損切りラインの置き場にも使われる。
ジグザグ細かい動きを消して山と谷だけを結ぶ。過去の波の把握用で、直近は確定しない（後から変わる）。
テクニカル（オシレーター系）›
CCI / ウィリアムズ%R / ROC / モメンタムいずれも「勢い」や「行きすぎ」を測る指標。RSI・ストキャスと役割が重なるため、当システムでは二重加点を避けて採用せず。
RCI（順位相関指数）日付と価格の順位相関。−80以下で売られすぎ。日本の個人投資家に人気。
アルティメット / デマーカー / TRIX / CMO / AO各種の派生オシレーター。基本はRSI・MACD・ストキャスで足りる。
サイコロジカルライン直近12日のうち上げた日の割合。25%以下は売られすぎ。
出来高・ボラティリティ›
VWAP出来高加重平均価格。その日の「平均的な約定値段」。日中トレード向けで、夜1回判断では出番が少ない。
VR / CMF / A/Dライン出来高で買い圧力・売り圧力を測る指標群。OBV・MFIと同系統。
価格帯別出来高どの値段で最も多く売買されたか。支持帯・抵抗帯の裏付けになる。当システムの「長期支持帯」の考え方に近い。
市場全体・需給・センチメント›
空売り比率 / 信用倍率 / 投資部門別売買需給の本丸。信用買い残の積み上がりは「将来の売り圧力」。J-Quants Standard以上で取得可（未導入）。
日経VI / VIX / プット・コール・レシオ恐怖指数。急騰時は投げ売り一巡の目安になることも。
マクレラン・オシレーター / ヒンデンブルグ・オーメン騰落データから作る市場全体のシグナル。後者は暴落の前兆として有名だが的中率は議論あり。
クオンツ・成績評価›
β / α / R²市場との連動性・超過収益・説明力。ポートフォリオ全体の性格を測る指標。
シャープ / ソルティノ / インフォメーション・レシオ取ったリスクに対してどれだけ稼いだか。検証レポートの成績を「リスク調整後」で見る次の段階で導入予定。
最大ドローダウン / VaR / 標準偏差最悪期の落ち込み・想定損失・ばらつき。「持ち株の管理」の通算成績に最大ドローダウンを追加するのが次の候補。
